# PLP Python Week 4: Functions Assignment

## Overview of Files

* `welcome.py` - Replaces repeated greeting print statements with a single reusable `welcome()` function that returns personalized welcome messages.
* `toolbox.py` - A collection of three utility functions (`double()`, `is_pass()`, and `greet()`) demonstrating parameter passing, boolean comparisons, default arguments, and return values.

## Reflection

The function `is_pass()` was the most insightful to write because it showed that comparison operations like `score >= 50` natively evaluate to a boolean value, removing the need for an explicit `if/else` block. Understanding default parameter values in `greet()` was also very practical for writing flexible functions.
